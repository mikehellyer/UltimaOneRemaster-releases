# Ultima I Remaster: releases

Installers for the Ultima I Remaster, for Windows, macOS and Linux (.deb). The game's
source code is kept private; this repository only holds the published builds.

**You need your own copy of Ultima I for DOS** (for example GOG's *Ultima 1+2+3*). No game
files are included. The first time the remaster runs it asks for the folder that holds the
original files (MAP.BIN, OUT.EXE and so on) and remembers it.

Download the installer for your system from [Releases](../../releases). When a newer version
is out, the game's main menu tells you; press U to download it.
